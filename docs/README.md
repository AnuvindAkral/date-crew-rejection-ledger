## Working history

The Gate B and review documents are the working record of how the product was designed, and they are kept because the reasoning matters more than the polish. They describe the state of the design at that point, and some of them have been superseded by the final build. Where they disagree with the code, the code is right.

`../phase1/` holds the original research, funnel diagnosis, decisions and experiment, preserved unchanged.
